AutoClicker

画面を見張って、見つけたら押す。Mac用の画像認識オートクリッカー。

About概要

「この画面が出たら、このボタンを押す」。AutoClickerは、それだけを自動でやってくれるMacアプリです。座標を指定するだけのオートクリッカーと違い、画面に出た画像を見て動くので、ボタンの出るタイミングがバラバラな作業にも使えます。iPhoneアプリの動作確認（検証用途）として、iPhoneミラーリングの画面も対象にできます。

  • 無料版をダウンロード近日公開

Use Casesこんな作業に

  • iPhoneアプリの動作確認：同じ操作を何十回も繰り返す、不具合の再現テスト
  • 定型作業の待ち受け：長い処理の途中で出る決まった確認ダイアログを、自動で進める
  • 画面操作のデモ・収録：毎回同じ操作を、同じ流れで再生する
  • 繰り返しのタップ操作：手でやると面倒な、決まった画面の繰り返し

Features特長

  • 画像認識で動く：押したいボタンの画像を登録すると、画面上で見つけてクリックします
  • 複数の動きを順番に登録できる：「Aを押す→Bが出るまで待つ→Cを押す」のような流れを組めます
  • iPhoneミラーリングでの動作検証：Macに映したiPhone画面を対象に、アプリの動作確認に使えます（検証用機能）
  • ウィンドウに追従：対象アプリのウィンドウが動いても、範囲がついていきます
  • キーボードショートカット：主な操作をキーボードで呼び出せます

Noticeご利用前にご確認ください

  • EU圏では使えません。iPhoneミラーリングがEU圏で提供されていないためです。
  • 現在のバージョンはApple Developer Programの署名を行っていないため、初回起動時にmacOSの警告が表示されます。開き方は下の案内をご覧ください。
  • 監視範囲は画面上の位置で保存されます。iPhoneの機種やミラーリング画面の大きさが変わると、範囲の再設定が必要です。
  • ゲームやWebサービスの中には、自動操作を禁止しているものがあります。ご利用前に各サービスの利用規約をご確認ください。ご利用による結果は、お客様の責任となります。
  • iPhoneミラーリングへの対応は、ご自身のアプリの動作検証を想定した機能です。他社のアプリやサービスへの利用は、各サービスの利用規約に従ってください。

First Launch初回起動時の警告

署名を行っていないため、初回は「開発元を確認できないため開けません」などの警告が出ます。アプリが壊れているわけではありません。次の順に開いてください。

  1. dmgを開き、AutoClickerを「アプリケーション」フォルダへコピーする。
  2. コピーしたAutoClickerをダブルクリックする。警告が出たら、「完了」で閉じる。
  3. 「システム設定 → プライバシーとセキュリティ」を開き、下部に表示される「AutoClickerはブロックされました」の横の「このまま開く」を選ぶ。
  4. 確認の画面で、Macのパスワードまたは Touch ID を入力し、「開く」を選ぶ。次回からは、そのまま開けます。

初回起動後、「画面収録」と「アクセシビリティ」の許可を求められます。システム設定の同じ画面でAutoClickerをオンにしてください。
